SuperDIM changelog
==================

1.3
----------------------

Added
 - Catalog tab - a database of the files inside archives:
   - Catalog allows instant search missing DAZ files (in case you deleted content library)
   - Scan the root of your entire DAZ Archives collection on PC to have access for the quick search of nested files in future!
   - Files list is kept in a local SQLite database (without unpacking the archives)
   - For every file the catalog shows its path, name, type, the modification date inside the archive (Modified), the archive path, name, type and the creation date of the archive file (ArchiveCreated)
   - Archives installed on the "Installer" tab are added to the catalog automatically
   - Search by part of the path (optionally ignoring case), sorting by any column, export/import to CSV
   - "Search & Install by file paths" button allows you quickly find all archives having the missing files list you provided: paste relative file paths that you see in DAZ Studio "Missing Files" window, and the archives containing them are put to the install list
   - CSV export / import

Install list:
 - Status column (Success, FAIL or the reason why the archive was not installed).
 - Prefix column (folder of the archive relative to the Root folder, shown when "Hierarhy by Root folder" is on).
 - Context menu "Copy full path".

Improved reliability of content installation:
 - Fixed access denied errors (uncheck Read-Only flag, check missing directories etc.)
 - Checking 7z/Unrar exit codes.
 - Fixed case when some content could be missing due to specific folder structure
 - UnRAR skips the Partial-mode folders (data, Runtime, Documentation ...) at any depth, like 7z.
 - Nesting of folders is compared as a path, not as a string prefix ("Hair\Short Curly" was lost as "nested" in "Hair\Short").
 - Nested archive with a shorter path of a top folder made the whole archive FAIL (ArgumentOutOfRangeException).
 - Root folder: the relative folder of an archive is computed safely (root of a drive is allowed, an archive outside the Root folder gives a warning in the log).
 - Improved heuristic analysis in root folder detector

Fixed some errors:
 - The Install button stayed disabled after an empty list or an error.
 - Volumes 2..N of a multi-volume RAR (name.partN.rar) are not added to the install list.
 - Fixed builder script

Other:
 - Main window can be resized.
 - Improved UI speed.
 - Code is under control of AI (Claude).
